

## 1. Introduction

File and folder management is an essential function of the Windows operating system. It allows users to create, organize, store, copy, move, rename and delete files and directories.

In this lab, I explored Windows File Explorer and performed practical exercises to understand how files and folders are managed.

## 2. Objectives

The objectives of this lab were to:

- Understand Windows file and folder management.
- Create files and folders.
- Rename files and folders.
- Copy and move files between directories.
- Delete and restore files.
- Understand file extensions.
- Organize files into directories.
- Become familiar with File Explorer operations.

## 3. Tools and Requirements

The following tools were used:

- Windows 10/11 operating system.
- File Explorer.
- Notepad.
- Keyboard and mouse.
- Recycle Bin.

## 4. Practical Exercises

### Task 1: Creating a Folder

**Procedure:**

1. Opened File Explorer using `Windows + E`.
2. Navigated to the Documents directory.
3. Right-clicked an empty area.
4. Selected New → Folder.
5. Created a folder named `Windows-Lab-02`.
6. Opened the newly created folder.

**Observation:**

Windows allows users to create directories to organize and store files.

### Task 2: Creating Text Files

**Procedure:**

1. Opened Notepad.
2. Entered the following text:

   `This is my second Windows practical lab.`

3. Selected File → Save As.
4. Saved the file as `Lab-Notes.txt` inside the `Windows-Lab-02` folder.
5. Created another text file named `Information.txt`.

**Observation:**

Notepad can be used to create and save text documents with the `.txt` extension.

### Task 3: Renaming Files and Folders

**Procedure:**

1. Located `Information.txt`.
2. Right-clicked the file.
3. Selected Rename.
4. Changed its name to `Windows-Information.txt`.
5. Renamed the main folder to `Windows-File-Management`.

**Observation:**

Windows provides several ways to rename files and folders, including the context menu and the F2 keyboard shortcut.

### Task 4: Copying Files

**Procedure:**

1. Selected `Lab-Notes.txt`.
2. Pressed `Ctrl + C` to copy the file.
3. Created another folder named `Backup`.
4. Opened the Backup folder.
5. Pressed `Ctrl + V` to paste the copied file.

**Observation:**

Copying creates another instance of a file while preserving the original file in its initial location.

### Task 5: Moving Files

**Procedure:**

1. Returned to the main folder.
2. Selected `Windows-Information.txt`.
3. Pressed `Ctrl + X`.
4. Opened the Backup folder.
5. Pressed `Ctrl + V`.

**Observation:**

Moving transfers a file from one location to another. Unlike copying, the original file is no longer present in its previous location.

### Task 6: Deleting and Restoring Files

**Procedure:**

1. Opened the Backup folder.
2. Selected `Windows-Information.txt`.
3. Pressed Delete.
4. Opened the Recycle Bin.
5. Located the deleted file.
6. Right-clicked the file and selected Restore.
7. Verified that the file returned to its original location.

**Observation:**

Files deleted using the normal Delete operation are generally moved to the Recycle Bin, where they can be restored before the bin is emptied.

### Task 7: Exploring File Extensions

**Procedure:**

1. Opened File Explorer.
2. Navigated to View → Show → File name extensions.
3. Enabled the display of file extensions.
4. Observed the extensions of the created text files.
5. Identified other common file extensions.

**Common File Extensions:**

| Extension | File Type |
|---|---|
| `.txt` | Text document |
| `.pdf` | Portable Document Format |
| `.jpg` | Image file |
| `.png` | Image file |
| `.exe` | Executable application |
| `.docx` | Microsoft Word document |
| `.xlsx` | Microsoft Excel spreadsheet |
| `.zip` | Compressed archive |

**Observation:**

File extensions help identify file formats and the applications commonly used to open them.

## 5. Windows Keyboard Shortcuts Learned

| Shortcut | Function |
|---|---|
| `Windows + E` | Open File Explorer |
| `Ctrl + Shift + N` | Create a new folder |
| `Ctrl + C` | Copy selected item |
| `Ctrl + X` | Cut selected item |
| `Ctrl + V` | Paste selected item |
| `Ctrl + Z` | Undo the previous action |
| `F2` | Rename selected item |
| `Delete` | Move selected item to Recycle Bin |
| `Shift + Delete` | Permanently delete selected item |
