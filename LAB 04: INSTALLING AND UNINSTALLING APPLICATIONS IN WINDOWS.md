

## 1. Introduction

This lab focuses on learning how to install, locate, manage, and uninstall applications in Windows 10.

Installing applications allows users to add software that provides additional functionality to a computer. Uninstalling removes applications that are no longer needed.

## 2. Objectives

The objectives of this lab were to:

- View applications installed on Windows.
- Download software from an official website.
- Install an application.
- Locate installed applications.
- Uninstall applications.
- Verify that an application has been removed.

## 3. Tools and Technologies

- Windows 10 Operating System
- Windows Settings
- Microsoft Edge or another web browser
- Notepad++
- Internet connection

## 4. Practical Exercises

### Task 1: View Installed Applications

1. Pressed `Windows + I` to open Settings.
2. Selected **Apps**.
3. Opened **Apps & features**.
4. Browsed the list of installed applications.
5. Identified applications installed on the computer.

**Observation:** Windows displays installed applications and provides options for managing or uninstalling supported applications.

### Task 2: Download an Application

1. Opened a web browser.
2. Visited the official Notepad++ website:

   https://notepad-plus-plus.org/downloads/

3. Located the latest stable release.
4. Downloaded the installer.
5. Waited for the download to finish.

**Observation:** Applications can be downloaded from their official websites.

### Task 3: Install Notepad++

1. Opened the Downloads folder.
2. Located the Notepad++ installer.
3. Double-clicked the installer.
4. Followed the installation instructions.
5. Accepted the licence agreement.
6. Completed the installation.
7. Opened Notepad++ from the Start Menu.

**Expected result:** Notepad++ should install and open successfully.

### Task 4: Locate the Installed Application

1. Opened the Start Menu.
2. Searched for `Notepad++`.
3. Located the application.
4. Right-clicked it to explore the available options.

**Observation:** The Start Menu provides a convenient way to search for and launch installed applications.

### Task 5: Uninstall Notepad++

1. Pressed `Windows + I` to open Settings.
2. Selected **Apps**.
3. Opened **Apps & features**.
4. Located Notepad++ in the application list.
5. Selected the application.
6. Clicked **Uninstall**.
7. Followed the prompts to complete the removal.

**Expected result:** Notepad++ should be removed from the installed applications list.

### Task 6: Verify Application Removal

1. Returned to **Apps & features**.
2. Searched for Notepad++.
3. Checked whether the application was still listed.

**Expected result:** Notepad++ should no longer appear in the installed applications list.

## 5. Observations

- Windows provides a central location for managing installed applications.
- Applications can be downloaded from official websites.
- Installation normally involves following a setup wizard.
- The Start Menu can be used to locate installed applications.
- Windows provides an uninstall option for supported applications.

## 6. Important Concepts

| Concept | Description |
|---|---|
| Installation | Adding software to a computer. |
| Uninstallation | Removing installed software. |
| Installer | A program used to install software. |
| Application | Software designed to perform a particular task. |
| Apps & features | Windows settings used to manage installed applications. |
| Start Menu | A Windows interface for finding and launching applications. |

## 7. Results

The installed applications list was accessed through Windows Settings.

The Notepad++ installation and uninstallation procedures were explored.

The final verification confirms whether the application was successfully removed.

## 8. Skills Acquired

- Navigating Windows Settings.
- Viewing installed applications.
- Downloading software from official websites.
- Installing Windows applications.
- Locating applications through the Start Menu.
- Uninstalling applications.
- Verifying application removal.

## 10. Conclusion

This practical lab introduced application management in Windows 10. It demonstrated how to view installed applications, download software, install applications, and remove software that is no longer required.

These skills are important for maintaining a Windows computer and managing its installed software.
