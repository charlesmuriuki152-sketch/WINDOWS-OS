

## 1. Introduction

This lab focuses on understanding the Windows desktop environment and learning how to navigate its main components.

It introduces the basic interface elements that users interact with when operating a Windows computer.

## 2. Objectives

By completing this lab, I aim to:

- Understand the Windows desktop environment.
- Explore the Start Menu.
- Identify and understand the Taskbar.
- Navigate File Explorer.
- Explore Windows Settings.
- Understand the functions of common Windows interface components.

## 3. Tools and Requirements

- Windows 10 or Windows 11 computer.
- Keyboard and mouse.
- File Explorer.
- Windows Settings.

## 4. Practical Exercises

### Task 1: Exploring the Windows Desktop

**Procedure:**

1. Start the computer and log in to Windows.
2. Observe the desktop environment.
3. Identify the desktop icons.
4. Right-click an empty area of the desktop.
5. Explore the available context menu options.

**Key observations:**

- The desktop is the main workspace in Windows.
- Desktop icons provide shortcuts to applications, files and folders.
- Right-clicking the desktop displays a context menu with additional options.

### Task 2: Exploring the Start Menu

**Procedure:**

1. Click the Windows Start button.
2. Explore the installed applications.
3. Locate the Power button.
4. Locate the Settings option.
5. Explore the available Start Menu options.

**Key observations:**

- The Start Menu provides access to installed applications.
- It provides access to Windows Settings.
- It provides power options such as shutdown and restart.

### Task 3: Exploring the Taskbar

**Procedure:**

1. Locate the Windows Taskbar.
2. Identify the Start button.
3. Locate the Search feature.
4. Identify pinned applications.
5. Locate the notification area.
6. Identify the system clock and date.

**Key observations:**

- The Taskbar provides quick access to applications.
- It displays running and pinned applications.
- The notification area displays system notifications and status information.

### Task 4: Exploring File Explorer

**Procedure:**

1. Press `Windows + E` to open File Explorer.
2. Locate Home or Quick Access.
3. Identify This PC.
4. Open the C: drive.
5. Explore the Documents, Downloads, Pictures and Desktop folders.

**Key observations:**

- File Explorer is used to manage files and folders.
- This PC provides access to available storage drives.
- The C: drive normally contains the Windows operating system and installed applications.
- Common folders provide locations for organizing personal files.

### Task 5: Exploring Windows Settings

**Procedure:**

1. Press `Windows + I` to open Windows Settings.
2. Explore the following categories:
   - System
   - Bluetooth & devices
   - Network & internet
   - Personalization
   - Apps
   - Accounts
   - Windows Update

**Key observations:**

- Windows Settings provides a central location for configuring the operating system.
- System settings manage display, sound and other system features.
- Network & internet provides network configuration options.
- Accounts provides user account management options.
- Windows Update provides access to operating system updates.

## 5. Keyboard Shortcuts Learned

| Shortcut | Function |
|---|---|
| Windows + E | Open File Explorer |
| Windows + I | Open Windows Settings |
| Windows key | Open Start Menu |
| Windows + D | Show Desktop |
| Windows + L | Lock the computer |
| Alt + Tab | Switch between open applications |

The lab introduced the Windows desktop environment and its main navigation components.

The exercises provided practical exposure to the Start Menu, Taskbar, File Explorer and Windows Settings.

## 7. Skills Acquired

- Windows desktop navigation.
- Basic application navigation.
- File Explorer navigation.
- Understanding Windows interface components.
- Identifying major Windows configuration categories.
