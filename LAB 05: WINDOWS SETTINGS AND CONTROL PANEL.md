

## 1. Introduction

This lab focuses on exploring Windows Settings and Control Panel in Windows 10.

Windows Settings and Control Panel provide interfaces for configuring and managing different aspects of the operating system.

## 2. Objectives

The objectives of this lab were to:

- Open and navigate Windows Settings.
- Explore the different Settings categories.
- Open and navigate Control Panel.
- Understand the different Control Panel categories.
- Change the Control Panel viewing options.
- Access basic computer system information.

## 3. Tools and Technologies

- Windows 10 Operating System
- Windows Settings
- Control Panel
- Run dialog box

## 4. Practical Exercises

### Task 1: Explore Windows Settings

1. Pressed `Windows + I` to open Settings.
2. Explored the following sections:
   - System
   - Devices
   - Network & Internet
   - Personalization
   - Apps
   - Accounts
   - Time & Language
   - Update & Security
3. Opened each section and observed the available options.

**Observation:** Windows Settings provides a central interface for configuring different operating system features.

### Task 2: Explore Control Panel

1. Pressed `Windows + R` to open the Run dialog box.
2. Typed `control`.
3. Pressed Enter to open Control Panel.
4. Changed the View by option to Category.
5. Explored the following categories:
   - System and Security
   - Network and Internet
   - Hardware and Sound
   - Programs
   - User Accounts
   - Appearance and Personalization
   - Clock and Region
   - Ease of Access

**Observation:** Control Panel provides access to traditional Windows configuration tools.

### Task 3: Change Control Panel View

1. Opened Control Panel.
2. Located the View by option in the upper-right corner.
3. Selected Large icons.
4. Observed how the layout changed.
5. Changed the view to Small icons.
6. Compared the three available viewing options.

**Observation:** Control Panel supports Category, Large icons, and Small icons views.

### Task 4: Open Specific Settings

The following keyboard shortcuts and commands were explored:

| Shortcut or Command | Function |
|---|---|
| `Windows + I` | Opens Windows Settings |
| `Windows + R` | Opens the Run dialog box |
| `control` | Opens Control Panel |
| `Windows + X` | Opens the Quick Link menu |

### Task 5: Explore System Information

1. Opened Control Panel.
2. Selected System and Security.
3. Selected System.
4. Observed the computer information displayed.

The information included:

- Windows edition
- Processor
- Installed RAM
- System type
- Computer name

**Observation:** Windows provides information about the computer's hardware and operating system.

## 5. Observations

- Windows Settings provides a modern interface for managing system configurations.
- Control Panel provides access to traditional configuration tools.
- Control Panel can display settings using different viewing options.
- The Run dialog box provides a quick way to open system utilities.
- Windows displays basic hardware and operating system information.

## 6. Important Concepts

| Concept | Description |
|---|---|
| Settings | Modern Windows interface for configuring the computer. |
| Control Panel | Traditional Windows interface for managing system settings. |
| System and Security | Contains system maintenance and security-related options. |
| Personalization | Allows users to customize Windows appearance. |
| System Information | Displays details about the computer and operating system. |
| Run Dialog | Windows utility used to open programs and system tools through commands. |

Windows Settings and Control Panel were explored.

Different Control Panel viewing options were examined, and the System section was used to identify basic computer information.
