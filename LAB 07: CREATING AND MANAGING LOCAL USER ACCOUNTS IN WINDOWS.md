

## 1. Introduction

This lab focuses on creating, viewing, switching between, and managing local user accounts in Windows 10.

Windows supports multiple user accounts, allowing different people to use the same computer while maintaining separate profiles, settings, and files.

## 2. Objectives

The objectives of this lab were to:

- View existing Windows user accounts.
- Create a new local user account.
- Identify different account types.
- Change a user's account type.
- Switch between user accounts.
- Remove a practice user account.

## 3. Tools and Technologies

- Windows 10 Operating System
- Windows Settings
- User Accounts
- Family & other users
- Ctrl + Alt + Delete options

## 4. Practical Exercises

### Task 1: View Existing User Accounts

1. Pressed `Windows + I` to open Settings.
2. Selected **Accounts**.
3. Opened **Your info**.
4. Observed the currently signed-in account.
5. Selected **Family & other users**.
6. Examined the other accounts listed on the computer.

**Observation:** Windows allows multiple users to have separate accounts on one computer.

### Task 2: Create a New Local User Account

1. Opened **Settings → Accounts**.
2. Selected **Family & other users**.
3. Clicked **Add someone else to this PC**.
4. Selected **I don't have this person's sign-in information**.
5. Selected **Add a user without a Microsoft account**.
6. Entered the username `WindowsLabUser`.
7. Created a password and completed the security questions.
8. Clicked **Next**.

**Expected result:** A new local user account named `WindowsLabUser` should appear.

### Task 3: View the New Account

1. Returned to **Settings → Accounts → Family & other users**.
2. Located `WindowsLabUser`.
3. Selected the account.
4. Explored the available account management options.

**Observation:** Windows displays additional options for managing individual user accounts.

### Task 4: Change the Account Type

1. Selected `WindowsLabUser`.
2. Clicked **Change account type**.
3. Examined the available account types:
   - Standard User
   - Administrator
4. Kept the account as **Standard User**.
5. Clicked OK.

**Observation:** Windows provides different account types with different levels of system privileges.

### Task 5: Switch Between User Accounts

1. Pressed `Ctrl + Alt + Delete`.
2. Selected **Switch user**.
3. Selected `WindowsLabUser`.
4. Entered the account password.
5. Observed the new user's desktop.

**Observation:** Windows allows users to switch between accounts without deleting the existing user session.

### Task 6: Remove the Practice Account

1. Signed out of `WindowsLabUser`.
2. Signed back into the original administrator account.
3. Opened **Settings → Accounts → Family & other users**.
4. Selected `WindowsLabUser`.
5. Clicked **Remove**.
6. Confirmed the removal.

**Observation:** Windows provides an option to remove local user accounts. Removing an account can also delete its local data.

## 5. Observations

- Windows supports multiple user accounts.
- Local accounts can be created without connecting them to a Microsoft account.
- Standard users have fewer administrative privileges than administrators.
- Users can switch between accounts.
- Administrators can manage and remove local user accounts.

## 6. Important Concepts

| Concept | Description |
|---|---|
| User Account | An identity used to access a computer. |
| Local Account | An account stored and managed on the computer itself. |
| Microsoft Account | An account connected to Microsoft's online services. |
| Standard User | An account with limited system permissions. |
| Administrator | An account with privileges to make system-wide changes. |
| User Profile | A personal Windows environment containing a user's settings and files. |
| Switch User | Allows another account to access the computer without deleting the current session. |

## 8. Skills Acquired

## 9. Cybersecurity Connection

Understanding user accounts is important in cybersecurity because:

- Users should receive only the permissions they need.
- Administrator accounts have greater control over a computer.
- Separate accounts help organize access to files and resources.
- Limiting unnecessary administrator privileges helps improve system security.



## 11. Conclusion

This practical lab introduced local user account management in Windows 10. It demonstrated how users can create accounts, identify account types, switch between users, and manage account access.

These skills provide an important foundation for Windows administration and cybersecurity, particularly in understanding user privileges and access control.
