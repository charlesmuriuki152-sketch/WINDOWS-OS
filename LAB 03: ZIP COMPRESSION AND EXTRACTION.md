

## 1. Introduction

This lab focuses on learning how to compress files into ZIP archives and extract them using Windows File Explorer and 7-Zip.

Compression helps combine multiple files into a single archive, making file storage and sharing easier. Extraction restores files from an archive into a normal folder.

## 2. Objectives

The objectives of this lab were to:

- Create files for compression practice.
- Compress multiple files into a ZIP archive.
- Understand how to use 7-Zip in Windows.
- Extract files from a ZIP archive.
- Verify that extracted files are accessible.

## 3. Tools and Technologies

- Windows Operating System
- File Explorer
- 7-Zip
- Notepad

## 4. Practical Exercises

### Task 1: Create a Practice Folder

1. Opened File Explorer using `Windows + E`.
2. Navigated to the Documents folder.
3. Created a folder named `Windows-Lab-03`.
4. Created two text files inside the folder:
   - `Information.txt`
   - `Notes.txt`

### Task 2: Select Files for Compression

1. Opened the `Windows-Lab-03` folder.
2. Selected both text files.
3. Right-clicked the selected files.
4. Located the 7-Zip option in the context menu.

**Observation:** Windows displayed the 7-Zip option, allowing the selected files to be compressed into an archive.

### Task 3: Compress Files Using 7-Zip

1. Selected both text files.
2. Right-clicked and moved the pointer over 7-Zip.
3. Selected **Add to archive**.
4. Selected `zip` as the archive format.
5. Clicked **OK** to create the archive.

**Expected result:** A ZIP archive containing both text files should appear in the folder.

### Task 4: Extract the ZIP Archive

1. Located the created ZIP archive.
2. Right-clicked the archive.
3. Selected the extraction option.
4. Chose a destination folder.
5. Started the extraction process.
6. Opened the extracted folder to verify the files.

**Expected result:** The extracted folder should contain `Information.txt` and `Notes.txt`.

### Task 5: Compress an Individual File

1. Selected `Notes.txt`.
2. Right-clicked the file.
3. Used 7-Zip to create a separate ZIP archive.
4. Checked that the archive was created.

## 5. Observations

- File Explorer allows users to select multiple files at once.
- 7-Zip provides additional archive and compression options.
- ZIP archives can contain multiple files.
- Extracting an archive makes its contents available as normal files.

## 6. Important Concepts

| Concept | Description |
|---|---|
| Compression | Combining files into an archive and potentially reducing their storage size. |
| ZIP | A common archive format used to store files together. |
| Extraction | Restoring files from an archive. |
| 7-Zip | Software used to create and extract compressed archives. |
| Archive | A file containing one or more stored files. |

## 7. Results

The practice folder and two text files were created successfully.

The files were selected, and the 7-Zip compression option was located.

The compression and extraction results should be verified before marking the remaining exercises as complete.

## 8. Skills Acquired

- Creating and organizing files in Windows.
- Selecting multiple files.
- Using the Windows context menu.
- Identifying compression options in 7-Zip.
- Understanding ZIP archives and extraction.

This practical lab introduced file compression and extraction in Windows. It demonstrated how multiple files can be selected and prepared for archiving using 7-Zip.
