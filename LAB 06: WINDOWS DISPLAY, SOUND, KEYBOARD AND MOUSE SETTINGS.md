

## 1. Introduction

This lab focuses on exploring and configuring basic display, sound, keyboard, and mouse settings in Windows 10.

Windows provides configuration options that allow users to customize how they interact with their computers and connected hardware devices.

## 2. Objectives

The objectives of this lab were to:

- Explore Windows display settings.
- Understand basic sound configuration.
- Explore keyboard and typing settings.
- Examine mouse configuration options.
- Explore Windows personalization settings.

## 3. Tools and Technologies

- Windows 10 Operating System
- Windows Settings
- Display Settings
- Sound Settings
- Mouse Settings
- Keyboard Settings
- Personalization Settings

## 4. Practical Exercises

### Task 1: Explore Display Settings

1. Right-clicked an empty area on the desktop.
2. Selected **Display settings**.
3. Explored the following options:
   - Display resolution
   - Display orientation
   - Scale and layout
   - Multiple displays, if available.
4. Observed the existing display configuration.

**Observation:** Windows provides options for managing screen resolution, orientation, and display layout.

### Task 2: Explore Sound Settings

1. Right-clicked the speaker icon on the taskbar.
2. Selected **Open Sound settings**.
3. Explored the following options:
   - Output device
   - Input device
   - Master volume
   - App volume and device preferences, if available.
4. Tested the available sound controls.

**Observation:** Windows allows users to manage audio input, output, and volume settings.

### Task 3: Explore Keyboard Settings

1. Pressed `Windows + I` to open Settings.
2. Selected **Devices**.
3. Selected **Typing**.
4. Explored the available typing and keyboard options.
5. Opened Advanced keyboard settings, if available.

**Observation:** Windows provides settings for managing typing preferences and keyboard behavior.

### Task 4: Explore Mouse Settings

1. Opened Windows Settings.
2. Selected **Devices**.
3. Selected **Mouse**.
4. Explored the following options:
   - Primary mouse button
   - Cursor scrolling
   - Scrolling speed
   - Additional mouse options.
5. Observed the existing mouse configuration.

**Observation:** Windows allows users to customize mouse buttons and scrolling behavior.

### Task 5: Explore Personalization Settings

1. Right-clicked an empty area on the desktop.
2. Selected **Personalize**.
3. Explored the following sections:
   - Background
   - Colors
   - Lock screen
   - Themes
   - Taskbar settings.
4. Observed the available customization options.

**Observation:** Windows provides personalization features that allow users to customize the appearance of the operating system.

## 5. Observations

- Display settings control screen resolution and orientation.
- Sound settings manage audio input and output devices.
- Keyboard settings provide typing-related configuration options.
- Mouse settings control button behavior and scrolling.
- Personalization settings allow users to customize the Windows interface.

## 6. Important Concepts

| Concept | Description |
|---|---|
| Display Resolution | Controls the number of pixels displayed on the screen. |
| Display Orientation | Controls screen direction, such as landscape or portrait. |
| Output Device | Selects where sound is played. |
| Input Device | Selects the microphone or sound input source. |
| Keyboard Settings | Controls typing-related preferences. |
| Mouse Settings | Controls mouse buttons and scrolling behavior. |
| Personalization | Controls the appearance of Windows. |
